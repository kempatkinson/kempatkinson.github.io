# Kemp Atkinson — Actor & Writer site

## Launch on GitHub Pages (about 5 minutes)

1. **Create a new GitHub account** at github.com/signup. Suggested usernames (all were free on Oct 14, 2026):
   - `thekempatkinson` → site at **thekempatkinson.github.io**
   - `kempatkinsonacts` → **kempatkinsonacts.github.io**
   - `kempatkinsonofficial` → **kempatkinsonofficial.github.io**
2. **Make a new repository** named exactly `USERNAME.github.io`, for example `thekempatkinson.github.io`. Set it to **Public**.
3. Click **"uploading an existing file"** and drag in `index.html` and the `images` folder. Then click **Commit changes**.
4. Go to **Settings → Pages**. Under "Build and deployment," pick **Deploy from a branch**, then **main** / **(root)**, and click **Save**.
5. Wait 1–2 minutes, then visit `https://USERNAME.github.io`.

## Things to fill in
Search `index.html` for `EDIT:` to find each spot.
- **Headshot:** save a photo as `images/headshot.jpg`. A portrait crop around 4:5 works best.
- **Email** in the Contact section (`you@example.com`).
- **Bio** in the top section.
- **Being a Hero** details.
- **Loglines and watch links** for Free Lunch and Wait for Gru.

## Reel
The reel plays from Google Drive. The file's sharing must be set to **"Anyone with the link"**, or visitors will see a sign-in box.

## Custom domain (optional)
If you buy something like kempatkinson.com, add it under Settings → Pages → Custom domain. Then follow GitHub's DNS instructions.
